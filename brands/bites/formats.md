# Bites — Formats

## Post Instagram

| Campo | Valor |
|---|---|
| aspect_ratio | 4:5 |
| dimensiones | 1080 × 1350 |
| usos | Post estático, producto en escena, hero |
| encuadre | Producto al centro o tercio dominante, fondo nocturno con acentos cálidos |

## Historia (Instagram Stories)

| Campo | Valor |
|---|---|
| aspect_ratio | 9:16 |
| dimensiones | 1080 × 1920 |
| usos | Teaser, promo flash, BTS |
| encuadre | Vertical, texto grande arriba, CTA abajo |

## Reel

| Campo | Valor |
|---|---|
| aspect_ratio | 9:16 |
| dimensiones | 1080 × 1920 |
| resolución | 720p |
| duración | 4–15s |
| usos | Producto en movimiento, ASMR de armado, antojo |
| motor | seedance_2_0 (mode=fast) |

## Carrusel

| Campo | Valor |
|---|---|
| aspect_ratio | 4:5 |
| dimensiones | 1080 × 1350 |
| slides | N (típicamente 4–6) |
| estructura | Hook → variedades / proceso → momento → CTA |
| render | Slide cover = AI; slides tipográficos = HTML→PNG (cuando aplique) |

## Overrides de motor por marca

Defaults vienen de `engines/router.md`. Bites no requiere overrides; usa los defaults.
Bites NO produce infografías — ese tipo no aplica para esta marca.
